# CSV Generator

CSV Generator is a React-based application that allows users to easily generate customized CSV files by specifying a range, starting number, and unique row data. This app provides an efficient way to create CSV files with a mix of user-input data and pre-defined values for rapid data preparation.

## Key Features
Range and Starting Number Selection:

Users can specify a range of rows to generate, as well as a starting number for sequential data generation, allowing for flexibility in CSV creation.
Customizable Row Data:

For each row within the selected range, users can input unique data that will be included in the CSV.
This enables precise control over each row’s content, while still allowing for the bulk generation of CSV data.
Pre-defined Data Columns:

Certain columns are automatically filled with pre-defined data values directly from the code.
This feature ensures that specific fields follow a consistent format or content, reducing repetitive input and improving efficiency.
One-click CSV Generation:

After defining the range, starting number, and row-specific data, users can generate the CSV with a single click.
A download link is provided immediately, allowing the generated CSV file to be saved and used as needed.
With these features, CSV Generator simplifies the process of creating structured CSV files by combining user-defined and automated data inputs, making it an ideal tool for generating standardized data quickly and effectively.
